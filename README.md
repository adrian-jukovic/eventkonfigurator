# Eventkonfigurator

Konfigurator-Widget für Licht/Sound/DJ-Verleih, eingebunden als HTML-Modul auf der IONOS-Website.

- `eventkonfigurator.html` — die eigentliche Quelle (Style + Markup + Script). Das ist der Code, der 1:1 in das IONOS HTML-Modul eingefügt wird.
- `index.html` — lädt `eventkonfigurator.html` zur Live-Vorschau (z. B. über Netlify), damit man Änderungen im Browser sehen kann, ohne sie erst bei IONOS einzufügen.
